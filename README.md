# Hey, I'm building useful open-source software 👋

I like turning ideas into polished, practical projects — from local AI tools to browser games and interactive learning experiences.

## ✨ Featured projects

### 🎙️ [Voice Dictate](https://github.com/pstarwars2026/voice-dictate)
> Free, offline voice-to-text for macOS on Apple Silicon

Hold a key, speak, and release to get polished text. Voice Dictate uses Google's Gemma 4 locally through MLX, with grammar cleanup, technical-term preservation, and Hindi/Hinglish-to-English translation.

### 🎮 [ContraRun](https://github.com/pstarwars2026/contra-run)
> Original Three.js 2.5D run-and-gun browser game

Three campaign zones, weapons, swimming, collapsing terrain, bosses, New Game+, keyboard/mouse/touch controls, and an original MIDI-note soundtrack rendered with Web Audio. It runs directly in the browser with no account or backend.

### 🕰️ [The Clockmaker's Postcards](https://github.com/pstarwars2026/where-next-detective-v2)
> A detailed 3D geography mystery

An interactive detective-style geography adventure built around observation, clues, place knowledge, and exploration. The project is open source under Apache-2.0.

### 🗺️ [Where Next Detective](https://github.com/pstarwars2026/where-next-detective)
> A colorful 3D geography detective adventure

The earlier 12-chapter geography game that helped shape the larger mystery-game direction.

## 💡 What I care about

- **Useful first** — projects should solve a real problem or create a genuinely enjoyable experience.
- **Open source** — code, setup, architecture, and limitations should be understandable to someone discovering the project for the first time.
- **Local when it makes sense** — privacy-sensitive AI should run on-device when practical.
- **Small details matter** — controls, documentation, tests, visual polish, and accessibility are part of the product.
