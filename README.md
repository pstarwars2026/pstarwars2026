### 🎙️ [Voice Dictate](https://github.com/pstarwars2026/voice-dictate)
> Free Superwhisper / Wispr Flow alternative for macOS

Hold a key → speak → release → polished text appears. Powered by Google's Gemma 4 running locally on Apple Silicon via MLX.

- ✅ Grammar correction & filler word removal
- ✅ Technical term preservation (code-aware)
- ✅ Hindi/Hinglish → English translation
- ✅ 100% offline, zero telemetry
